# نظام إدارة المجندين

تطبيق مكتبي عربي لإدارة بيانات المجندين ومتابعة الإجازات والتنقلات بين المواقع.

## الوظائف الحالية

- تسجيل دخول المسؤولين بالرقم العسكري وكلمة المرور.
- قاعدة بيانات SQLite محلية تُحفظ على جهاز الكمبيوتر.
- فصل حسابات المستخدمين وكلمات المرور عن سجلات المجندين؛ تُمنح حسابات الدخول للمسؤولين فقط.
- جدول `soldiers` يكون الرقم العسكري فيه هو المفتاح الأساسي.
- استيراد بيانات المجندين من ملفات Excel وCSV، مع نموذج Excel قابل للتنزيل.
- إضافة وتعديل وفلترة جميع الحقول: الرقم العسكري، الدرجة، الاسم، السرية، المكان الفرعي، الرقم القومي، الرقم الثلاثي، تواريخ الضم والتسريح والتجنيد، المحافظة، المركز، الديانة، مركز التدريب، والسلاح.
- قسم مستقل لإدارة حسابات المسؤولين وربط كل حساب برقم عسكري.
- سجلات الإجازات والتنقلات بين المواقع.
- تغيير كلمة المرور المؤقتة عند أول تسجيل دخول.
- تصدير قاعدة البيانات واستعادتها من نسخة JSON احتياطية.

## التشغيل

ثبّت الاعتماديات:

```powershell
npm install
```

لتشغيل واجهة Vite، ابدأها في نافذة طرفية:

```powershell
npm run dev
```

ثم شغّل Electron في نافذة طرفية أخرى:

```powershell
npm run electron:dev
```

في أول تشغيل، أنشئ حساب المسؤول الأول واربطه برقم عسكري موجود أو جديد. بعد تسجيل الدخول غيّر كلمة مروره، ثم استورد بيانات المجندين من تبويب «المجندون». لا تُنشأ حسابات دخول عند الاستيراد؛ استخدم قسم «المستخدمون» لإنشاء حساب مسؤول وربطه بمجند محدد. الدور المتاح حالياً هو «مسؤول» فقط.

## التشغيل في المتصفح

للتطوير في المتصفح، شغّل الخادم المحلي وواجهة Vite في نافذتين طرفيتين:

```powershell
npm run dev
```

```powershell
npm run electron:dev:browser
```

افتح `http://localhost:3000` في المتصفح. يعمل الخادم عبر Electron على الجهاز نفسه، ويستخدم ملف SQLite نفسه الذي يستخدمه تطبيق سطح المكتب. اترك نافذتي الطرفية مفتوحتين أثناء الاستخدام.

للتشغيل من نسخة الواجهة المبنية، أغلق تطبيق سطح المكتب أولاً، ثم نفّذ `npm run build` وبعد اكتماله شغّل `npm run browser:server` واترك نافذته مفتوحة. افتح `http://127.0.0.1:3001`، وأوقف الخادم بإغلاق نافذته.

إذا كان المنفذ 3001 مستخدماً، عيّن `$env:WORKER_API_PORT = "3002"` في نافذتي Vite وElectron قبل تشغيلهما، ثم استخدم المنفذ الجديد في عنوان المتصفح.

## إنشاء نسخة Windows

```powershell
npm run electron:build
```

يُحفظ ملف التثبيت في مجلد `release/`.

## تنظيف قاعدة البيانات بالكامل

أغلق التطبيق أولاً. شغّل الأمر بدون تأكيد لمعاينة الإجراء؛ لن تُحذف بيانات. لتنفيذ إعادة الضبط، شغّل:

```powershell
npm run database:clean -- --confirm-full-reset
```

يحفظ السكربت نسخة JSON احتياطية داخل مجلد `backups` في مسار بيانات التطبيق قبل حذف جميع الحسابات والمجندين وسجلات الإجازات والتنقلات. ستظهر شاشة الإعداد الأول عند تشغيل التطبيق مجدداً. تحتوي النسخة الاحتياطية على تجزئات كلمات المرور، لذا احفظها بأمان.

## بيانات Excel وقاعدة البيانات

يتضمن نموذج Excel الأعمدة العربية المقابلة للحقول الخمسة عشر في جدول المجندين؛ الرقم العسكري والاسم مطلوبان والرقم العسكري فريد. تدعم عملية الاستيراد العناوين العربية والإنجليزية المقابلة.

تُخزّن كلمات المرور في جدول `users` المنفصل عن جدول `soldiers` على هيئة تجزئات مملحة، ويرتبط كل حساب بالرقم العسكري. تنقل ترقية قاعدة البيانات سجلات العاملين القديمة إلى جدول المجندين وتحافظ على حسابات المستخدمين وسجلات الإجازات والتنقلات. تدعم الاستعادة نسخ JSON القديمة والجديدة.
